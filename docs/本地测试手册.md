# EchoMem 本地测试手册

本文档用于你在本地独立完成 EchoMem 的功能验证与回归测试。

## 1. 测试前准备

### 1.1 Python 环境
- 推荐 Python `3.11+`（你当前 3.13 也可用）
- 在项目根目录执行命令

### 1.2 Conda 环境（推荐）
如果你使用 `conda`，建议先创建独立测试环境：

```bash
conda create -n echomem-test python=3.11 -y
conda activate echomem-test
```

安装基础依赖（最小运行集）：

```bash
pip install streamlit pandas
```

如果你要测试可选向量检索 `chroma`：

```bash
pip install chromadb
```

### 1.3 配置文件
1. 检查 [settings.toml](/Users/yelainab/project/EchoMem/config/settings.toml) 中的非敏感默认项
2. 准备 `.env`（真实 API Key 和 API Base URL 统一放这里，或使用运行环境变量覆盖）

建议最小 `.env`：

```bash
MIMO_API_KEY=你的真实key
MIMO_BASE_URL=https://token-plan-cn.xiaomimimo.com/v1
```

## 2. 快速健康检查

### 2.1 编译检查
```bash
python -m py_compile ui/app.py agent/tools/memory_search.py
```

### 2.2 单元测试
```bash
python -m unittest discover -s tests -p "test_*.py"
```

### 2.3 Baseline 样例评测
```bash
python experiments/run_baselines.py --data experiments/data/sample_eval.jsonl
```

## 3. 一键工作流测试

### 3.1 离线工作流（不依赖外网 API）
```bash
python scripts/workflow.py
```

可选密钥扫描：
```bash
python scripts/workflow.py --include-secret-scan
```

可选严格密钥扫描：
```bash
python scripts/workflow.py --include-secret-scan --strict-secrets
```

如果你需要对白名单做精确豁免（正则一行一个）：
```bash
python scripts/workflow.py --include-secret-scan --strict-secrets --secret-allowlist-file .secret-scan-allowlist
```

### 3.2 在线工作流（含 MiMo 实时调用）
```bash
python scripts/workflow.py --live-api
```

通过标准：
- Compile / Unit Tests / Baseline Eval 全部 `[OK]`
- `--live-api` 时 `Live E2E` 也为 `[OK]`

说明：当前交付验收默认跳过 API key 泄漏审查。若单独需要密钥扫描，可显式运行 `python scripts/workflow.py --include-secret-scan`。

## 4. UI 本地测试（重点）

### 4.1 启动 UI
```bash
streamlit run ui/app.py
```

如果你在非项目根目录启动，建议先 `cd /Users/yelainab/project/EchoMem` 再执行上面命令。

### 4.2 你需要手动验证的点
1. 页面可正常打开，样式加载正常（标题、卡片、图表）
2. `Current User` 可切换
3. 聊天输入后有 assistant 回复（真实 orchestrator 调用）
4. `Retrieval Explainability` 出现命中卡片
5. 侧边栏参数生效：
   - `Backend` 切换
   - `Candidate K / Top K / Decay λ` 调整
   - `Status / Type Filter` 过滤生效
6. `Persist Chat to LTM` 开启时，聊天后 `Memory Timeline` 数据增加
7. 点击 `Clear Session Chat` 会话被清空并重置

## 6. 常见问题排查

### 6.1 `MiMoAdapter requires api_key`
- 说明有效配置未读到 key
- 检查 `.env` 和当前 shell 环境变量；`config/settings.toml` 默认不再保存真实 Key

### 6.2 `Live E2E` 失败但离线通过
- 通常是网络或 API 配置问题
- 先单独运行：
```bash
PYTHONPATH=. python examples/orchestrator_e2e_example.py
```

### 6.3 `Secret Scan` 报告密钥命中
- 默认 `python scripts/workflow.py` 不运行密钥扫描
- 使用 `--include-secret-scan` 时会运行密钥扫描
- 如果命中文档或配置中的真实 Key，应迁移到 `.env` 或运行环境变量，并用占位说明替代明文
- 现在支持两种豁免方式（建议优先用 allowlist 文件，避免改代码）：
  - 行内标记：在误报行添加 `secret-scan: allow`
  - allowlist 文件：`--secret-allowlist-file <path>`，每行一个正则，`#` 开头为注释

## 7. 建议测试顺序（你自己跑）

1. `python scripts/workflow.py`

3. `streamlit run ui/app.py` 做 UI 手动验收

```bash

```
