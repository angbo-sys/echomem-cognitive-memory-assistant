## 3. 已知 Bug

### 🟡 数学公式增强渲染仍可改进

聊天与知识分析文本已增加 LaTeX 可读 fallback。`$E=mc^2$` 会显示为 inline 公式片段，`$$\sum_{i=1}^n i$$` 会显示为块级公式片段；`$10` 这类价格不会被误判为公式。

剩余问题：KaTeX CDN 增强渲染仍可能被 Streamlit 沙盒/CSP 拦截，因此当前交付标准是“可读、不乱码”，不是“完整排版成 KaTeX 数学字体”。

根因推测：
1. Streamlit CSP 可能拦截外部 CDN `<script>` 标签
2. KaTeX JS 加载时序与 MutationObserver 冲突
3. `$` 符号被误判（价格/引用 vs LaTeX）

### 🟡 环境变量覆盖测试配置风险

曾出现 `DEEPSEEK_BASE_URL` 用户环境变量影响 `tests/test_config_loader.py` 的情况。当前本地全量测试已通过，但跨机器运行时仍需留意环境变量污染。

### 🟡 Cognee 本地初始化仍有少量包级横幅

Cognee Cloud 可用时已跳过本地包导入；本地模式已设置 `COGNEE_SKIP_CONNECTION_TEST=true`，避免误导性的 LLM authentication failed 探测。剩余现象主要是 Cognee 包自身初始化横幅、日志文件和少量资源警告，当前不阻断交付。

### 🟡 UI 缺少自动截图回归

本轮 UI 已通过编译、组件测试、检索测试和 Streamlit HTTP smoke，但 Codex 内置浏览器连接本地 Streamlit 时超时，未完成桌面/移动截图级验收。后续建议加入 Playwright 或浏览器截图回归，覆盖会话、总览、记忆框架、用户画像、系统能力五页。
